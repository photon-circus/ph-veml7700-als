# Security policy

Report potential vulnerabilities privately to the repository owner. Do not
open a public issue for a flaw that could silently corrupt measurements or
promote nominal/model output as calibrated physical evidence.

The crate is Incubating and unpublished, with candidate version
`0.1.0-incubating.1`; it has no supported release series. Security reports
affecting the code on `main` receive best-effort fixes. When a release is
published, this policy will identify supported versions explicitly.
